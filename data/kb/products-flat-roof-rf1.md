# RoofFlat RF-1 south-facing ballasted system

RF-1 is a flat-roof system with modules facing south. It is held by ballast and does not pierce the roof membrane.

## Specifications

| Parameter | Value |
| --- | --- |
| Material | Aluminium, anodised |
| Coating thickness | 15 µm anodic layer |
| Fasteners | Stainless steel A2 |
| Corrosivity category | C3 |
| Tilt angle | 10° or 15° |
| Maximum wind speed | 28 m/s |
| Maximum snow load | 2.0 kN/m² |
| Added roof load | 18 to 30 kg/m², including ballast |
| Maximum roof slope | 5° |

## Notes

- The ballast weight depends on the wind load at the site and on the position on the roof. Corners and edges need more ballast.
- A protective mat goes under every base to protect the membrane.
- RF-1 needs a positive roof assessment before installation.
