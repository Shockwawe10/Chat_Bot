# GroundFrame GF-1 single-post ground-mount system

GF-1 is a ground-mount system with one row of posts per table. It is the standard choice for open land away from the sea.

## Specifications

| Parameter | Value |
| --- | --- |
| Material | Steel, hot-dip galvanised |
| Coating thickness | 85 µm average |
| Corrosivity category | C4 |
| Module layout | 2 modules in portrait per table row |
| Tilt angle | 15° to 35° |
| Maximum wind speed | 32 m/s |
| Maximum snow load | 2.4 kN/m² |
| Ground clearance | At least 0.8 m |
| Foundation | Rammed posts or screw piles |
| Typical plant size | 500 kWp to 50 MWp |

## Where not to use it

GF-1 is not used in corrosivity category C5, for example within 10 km of the sea. GroundFrame GF-2 is used there instead. Installing GF-1 at a site with a higher corrosivity category than C4 voids the coating warranty.

## Terrain

GF-1 can follow terrain slopes of up to 15% in the north-south direction without earthworks.
