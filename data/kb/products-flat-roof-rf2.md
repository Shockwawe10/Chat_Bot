# RoofFlat RF-2 east-west ballasted system

RF-2 is a flat-roof system with modules facing east and west in pairs. The low tilt and closed shape catch less wind, so it needs less ballast than RF-1.

## Specifications

| Parameter | Value |
| --- | --- |
| Material | Aluminium, anodised |
| Coating thickness | 20 µm anodic layer |
| Fasteners | Stainless steel A4 |
| Corrosivity category | C4 |
| Tilt angle | 10° |
| Maximum wind speed | 30 m/s |
| Maximum snow load | 2.4 kN/m² |
| Added roof load | 12 to 20 kg/m², including ballast |
| Maximum roof slope | 5° |

## Notes

- RF-2 fits about 20% more modules on the same roof area than RF-1.
- It is the usual choice for roofs with a low load reserve.
- RF-2 needs a positive roof assessment before installation.
